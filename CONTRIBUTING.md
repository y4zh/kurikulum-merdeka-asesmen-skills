# Contributing

Contributions are welcome: corrections to rules, better checklists, and clearer
wording all help teachers who rely on these skills.

## Ground rules

1. One level per skill. Never move a rule from one level's skill into another; if a
   rule truly applies to several levels, state it in each level's own words with that
   level's parameters.
2. Cite or label. Every framework claim needs a citation to an official
   Kemendikdasmen document (document name and page), or an explicit label that it is
   a practice rule or a school policy. Uncited claims presented as regulation will be
   rejected.
3. Stay universal. The skills serve any Indonesian school using Kurikulum Merdeka.
   Do not add a specific school, product, or platform name as if it were the standard;
   refer to CBT and LMS platforms generically.
4. Keep the format. Each skill keeps the five-section structure (Modul Ajar,
   Stimulus, Asesmen, Telaah, Konverter), a routing table at the top, and its detail
   in `references/`. Update the single-file Gemini build in `adapters/gemini/` when a
   skill changes.
5. Write rules in the language of the file you are editing; the skills are in English
   with Indonesian technical terms kept in Indonesian.

## How to propose a change

Open an issue describing the rule and its source, or send a pull request with the
edit and the citation. For regulation changes, link the official document.
