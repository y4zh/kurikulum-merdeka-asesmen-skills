# Format Dokumen PAUD & TK/RA

Reference for the konverter_paud_tk skill: layout rules and field structures for the four document types this level uses.

Note on sources: these formats are working designs of this skill, not official government forms. Schools with their own mandated report format keep their format; this skill then converts the instrument set into that format's fields instead, and says so in the delivery note.

## 1. Layout rules for all documents

- Handwriting first: rows at least 1 cm high for tick columns and 1.5 cm where notes are written; a teacher fills these standing up, mid-play.
- Few items per page: one observation sheet carries one play session's indicators for one group, never a whole semester squeezed onto a page.
- Headers survive photocopying: identity in plain text at the top, no meaning carried by colour or shading alone.
- Every sheet names its instrument source (goal and CP element) so a filed sheet can be traced back to the set it came from.

## 2. Lembar Observasi: field structure

Header block:

- Satuan Pendidikan
- Kelompok Usia dan Kelas (KB, TK A, or TK B, plus the class name)
- Elemen CP dan Tujuan
- Tema dan Subtema
- Konteks Bermain (centre, area, or activity)
- Tanggal dan Nama Guru

Body: one row per child per indicator, or one row per indicator with a class grid, as the source set specifies. Columns: Nama Anak, Indikator (printed in full), Teramati (tick), Belum Teramati (tick), Catatan Singkat. A closing block holds the teacher's follow-up note for the next meeting's stimulation.

## 3. Format Catatan Anekdot: field structure

One record per significant moment, or a running log with the same fields repeated:

- Nama Anak, Tanggal, Konteks (activity, place, who else was involved)
- Catatan Fakta: what the child did and said, in factual language, the child's own words quoted where they matter
- Tafsiran (diisi kemudian): the indicator this moment evidences, and what it suggests about the child's current category on that indicator
- Tindak Lanjut: the stimulation to offer next

The physical separation of Catatan Fakta and Tafsiran on the page is a requirement, not a style choice: it keeps later judgement from rewriting the record.

## 4. Ceklist Portofolio: field structure

One checklist per child per element, covering one semester:

Header: child name, kelompok usia and class, element, teacher.

Rows: one per evidence entry the plan expects (work sample types, construction photographs, anecdote references), with columns: Jenis Bukti, Tanggal Dikumpulkan, Indikator yang Dibuktikan, Catatan Guru (one line naming what the entry shows). A closing section lists gaps: indicators with no evidence yet, which is the checklist's real purpose mid-semester.

## 5. Format Laporan Perkembangan Anak: structure

The semester report to parents, one per child:

Header: school identity, child name, kelompok usia and class, semester and academic year, teacher.

Body, repeated per CP element (Nilai Agama dan Budi Pekerti; Jati Diri; Dasar Literasi, Matematika, Sains, Teknologi, Rekayasa, dan Seni):

- Kategori Capaian: one of BB (Belum Berkembang), MB (Mulai Berkembang), BSH (Berkembang Sesuai Harapan), BSB (Berkembang Sangat Baik), taken from the interpretation guide's judgement, never averaged across indicators into a score.
- Narasi Perkembangan: a short paragraph in parent-readable language describing what the child does now, with one or two concrete examples from observation or portfolio evidence.
- Stimulasi Lanjutan: what the school will offer next semester, and one simple suggestion for home that matches it.

Closing: a space for the teacher's overall note, the parent's response, and signatures. The report contains no numbers, no class rank, and no comparison with other children, anywhere.
