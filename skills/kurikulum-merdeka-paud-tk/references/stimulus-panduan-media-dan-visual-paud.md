# Panduan Media dan Visual PAUD & TK/RA

Reference for the kurikulum_merdeka_paud_tk skill (Bagian 2, Stimulus & Media): calibration for young children, media types, curated image sources, and the media specification format.

Note on sources: every figure in this file is a practical default of this skill. Official documents set no word counts, picture sizes, or text lengths for this level, because its assessment media are oral and concrete (the level's assessment basis is observation and performance, PPA Edisi Revisi 2025, p. 45). Never present these defaults as Kemendikdasmen rules.

## 1. Calibration for young children (practical defaults)

| Aspect | KB (about 2-4 years) | TK A (about 4-5 years) | TK B (about 5-6 years) |
| --- | --- | --- | --- |
| Spoken prompt length | 3-5 words per instruction, one instruction at a time | About 4-7 words, up to two linked instructions | About 5-8 words, a short sequence of instructions |
| Picture story | 3 frames, one event per frame | 3-4 frames | 4-6 frames, a simple cause and result |
| Picture character | One large object per card, plain background | One scene, few objects, one clear focus | One scene with several readable details |
| Real-object sets | Big pieces, 2-3 categories to sort | Pieces sized for small hands, 3-4 categories | Fuller sets, patterns and sequences possible |
| Song and movement | Very short, one repeated movement | Short verse, movements mirror the words | Longer song, movement sequence to remember |

Vocabulary comes from the child's daily life: family, home, school, food, animals, weather, the garden, the market. Introduce at most a few new words per medium, and let the medium itself show what they mean.

## 2. Media types and when to use them

- Real objects (realia): for sorting, matching, counting, pouring, planting, cooking, and care activities. First choice whenever safe and available.
- Large picture cards: for naming, finding, comparing, and talking when the real object is unavailable, unsafe, or out of season. One focus per card, thick outlines, clear contrast, printed large enough to read across the circle.
- Picture-story sequences: for sequencing, retelling, and predicting. The order must not be guessable from one frame alone, or the sequence measures nothing.
- Songs, rhymes, and movement: for memory, sequence, body coordination, and joy. The response the teacher observes is in the words sung, the movement matched, or the order kept.
- Puppets and role-play props: for language and social behaviour. A puppet lets a shy child answer through a character; observe the child's language and choices, not acting talent.
- Felt-board and magnetic sets: for retelling and arranging, where pieces can be moved and re-moved while the child talks.

## 3. Curated sources for real images

When a real photograph is genuinely needed (an animal the school cannot keep, a natural phenomenon), search open sources first and cite the source under the visual every time:

- Wikimedia Commons (commons.wikimedia.org): open-licensed photographs of animals, plants, natural phenomena, and places.
- BMKG (bmkg.go.id): Indonesian weather and sky imagery, when a weather picture must be real.

If no open source supplies a suitable image, draw the picture or write a specification box instead of using an uncredited image from elsewhere.

## 4. [SPESIFIKASI MEDIA] block format

Use this exact block when the medium is a physical set or scene a teacher must assemble. Fill every field; the key objects are what the child's response depends on, and the function line is the functionality test stated in advance.

```text
[SPESIFIKASI MEDIA]
Jenis Media    : Set Benda Nyata / Kartu Gambar Besar / Rangkaian Cerita Bergambar / Lagu dan Gerakan
Isi dan Jumlah : Daun asli 3 bentuk berbeda, masing-masing 6 helai, ukuran minimal sebesar telapak tangan anak; 3 keranjang sortir.
Objek Kunci    : 1) Perbedaan bentuk tepi daun (halus, bergerigi, membulat), 2) Jumlah daun tiap bentuk sama banyak.
Keamanan       : Daun tidak beracun, dicuci sebelum dipakai, tidak ada bagian tajam; benda kecil tidak dipakai untuk kelompok KB.
Penyajian      : Guru menunjukkan satu daun tiap bentuk, menyebut namanya, lalu mengundang anak mengambil dan mengelompokkan daun ke keranjang.
Fungsi         : Anak mengelompokkan berdasarkan bentuk tepi daun; respons tidak mungkin tepat tanpa melihat dan memegang daunnya.
```

## 5. Print and display checks

- Readable across the circle: if the medium is shown to a group, every child must see the key objects from where they sit.
- Contrast and size beat detail: fewer, bigger elements always win at this level.
- Laminate or mount handling materials where possible; media that fall apart in small hands end the activity, not the assessment.
- Check the medium with the functionality test one last time in its final physical form, not only in the draft.
