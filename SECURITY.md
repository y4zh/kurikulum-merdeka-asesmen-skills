# Security Policy

## Reporting a problem

If you find a security problem in this repository (for example a leaked credential
in a file, or a manifest that points outside the repository), report it privately
through GitHub's private vulnerability reporting on this repository, or by opening
an issue marked as a security concern without including the sensitive detail itself.

## Scope notes

- This package is documentation and agent instructions. It contains no executable
  code beyond the Cline plugin stub, which registers no capabilities.
- The skills never ask for, store, or transmit credentials. If a skill file appears
  to request credentials or personal data, treat that copy as tampered and report it.
- Assessment content produced with these skills is the user's responsibility to
  review before use in a real examination.
