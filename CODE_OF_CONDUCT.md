# Code of Conduct

This project follows the Contributor Covenant, version 2.1, in full. The canonical
text lives at https://www.contributor-covenant.org/version/2/1/code_of_conduct/.

In short: be respectful and constructive, welcome newcomers, focus on the work, and
do not harass or exclude anyone. Maintainers may moderate comments, issues, and pull
requests that break these standards. Report problems through a GitHub issue or the
repository owner's GitHub profile.
